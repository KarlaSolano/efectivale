## Versiones  
<ul>
    <li> Node >= 18 </li>
    <li> Php 8.2.12</li>
    <li> Composer 2.4.1</li>
    <li> Xampp v3.3.0</li>
    <li> Laravel 11</li>
</ul>


### Instalación

<ol>
    <li> Clonar el repositorio </li>
    <li> Creae archivo .env </li>
    <li> Crear DB efectivale </li>
    <li> Ejecutar php artisan migrate</li>
    <li> Ejecutar Npm: npm run dev </li>
    <li> Ejecutar Composer: composeer run dev </li>
    
</ol>
